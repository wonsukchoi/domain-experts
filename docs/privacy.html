Privacy Policy

Last updated 2026-07-30

Domain Experts (domainexperts.dev) is a static, open source site. It has no accounts, no forms, and no server-side backend — everything you see is a pre-built HTML page served over CDN. This page explains what little data collection exists.

Analytics

This site uses Umami, a self-hosted, open source analytics tool, running at analytics.wonsukchoi.com. Umami does not use cookies and does not track you across other sites. It records anonymized, aggregate counts — page views and referrers — without collecting IP addresses, device fingerprints, or any other personally identifying information.

Fonts

Page text uses the Inter and JetBrains Mono typefaces, loaded from Google Fonts (fonts.googleapis.com, fonts.gstatic.com). Loading a font from Google's servers exposes your IP address and browser details to Google in the same way any third-party resource request does; Google's font-serving endpoint does not set cookies. See Google Fonts' own privacy FAQ for details.

What this site does not do

  • No accounts, logins, or user-submitted data of any kind — the Content-Security-Policy on every page sets form-action 'none', and there are no forms.
  • No cookies are set by this site.
  • No data is sold or shared with third parties beyond the analytics and font requests described above.
