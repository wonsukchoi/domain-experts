Claude skills for every profession

what they are and how to install one

A Claude skill is a folder with a SKILL.md file of instructions that Claude loads when a task needs it. In Anthropic's words, Agent Skills are “modular capabilities that extend Claude’s functionality. Each Skill packages instructions, metadata, and optional resources (scripts, templates) that Claude uses automatically when relevant.” In Claude Code, skills live in .claude/skills/<name>/SKILL.md, and you can also call one directly with /skill-name (Claude Code skills docs).

Domain Experts is an open source library of skills for jobs rather than tools: each one holds the decision thresholds, trade-off rules and failure modes of a real role, such as a contracts lawyer or a financial analyst, so the agent reasons like that practitioner instead of like a generalist.

How to add a skill to Claude Code

One command copies a role into your project. No install is needed first: npx fetches the CLI from npm.

npx domain-experts add lawyer-contracts
# Installed lawyer-contracts (SKILL.md + references/ (4 files)) -> ./.claude/skills/lawyer-contracts

That writes ./.claude/skills/lawyer-contracts/SKILL.md plus its references/ folder (artifacts, red flags, vocabulary). Start a new Claude Code session in that project and the skill is available. Useful options:

  • --to <dir> installs somewhere other than .claude/skills/.
  • --country <iso2> installs only one jurisdiction overlay for roles that have them.
  • npx domain-experts preview <slug> prints a role's identity and worked example without installing anything.
  • npx domain-experts update re-fetches every installed role.

Not sure which role? Let it match

npx domain-experts match "review this vendor contract like a lawyer"

Or install the /domain-expert command once and skip the lookup:

npx domain-experts command          # writes .claude/commands/domain-expert.md
# restart Claude Code, then:
/domain-expert review this vendor contract

The command matches the task to a role, loads its SKILL.md (and references/ when needed) and answers as that role, or says plainly that no role covers the task yet. npx domain-experts init <slug> sets up the router skill, the command and a role in one step.

Examples

Three of the 950+ roles in the role index:

  • Legal: lawyer-contracts — clause playbooks and fallback positions for reviewing and negotiating commercial contracts. npx domain-experts add lawyer-contracts
  • Finance: financial-analyst — turns business decisions into numbers that can be compared honestly, and numbers back into decisions. npx domain-experts add financial-analyst
  • Healthcare: registered-nurse — spotting early deterioration from vital-sign trends, prioritising patients by acuity and escalating a change in condition (SBAR). npx domain-experts add registered-nurse

Every role is marked draft: none has been reviewed by a practitioner yet, and the evals in the repo cover some roles, not all (see About). Treat the output as a well-structured second opinion, not professional advice.

FAQ

Do these skills work outside Claude Code?

Yes. SKILL.md is a cross-tool format, and Claude Code skills follow the Agent Skills open standard. The /domain-expert command installs for Claude Code, Codex, Gemini CLI, Cursor, Windsurf, Roo Code and Amp with --tool <id>; the README has per-tool install paths.

Why not install every role at once?

Claude Code reads the name and description of every discovered skill at the start of a session, so hundreds of installed roles cost tokens every time. Install the roles you use, or the single router skill (npx domain-experts add domain-expert-router), which reads a role only when a task needs it.

What is the difference between a skill and an agent?

A skill is knowledge and instructions the agent loads; the agent is the thing doing the work. A Domain Experts role does not run anything by itself: it changes how Claude reasons about a task in that profession.
